Port checking

browser limits apply

A browser cannot open raw TCP sockets, so no web page can port-scan a host. Anything claiming otherwise is guessing. This console probes what a browser can actually see (HTTPS reachability and timing) and hands you the exact command to do the real scan from a shell.
